## Validation Scope

Each review below passed 153 project tests, `npm run check`, and `npm run check:provenance`; the 3.1.0 and 3.1.1 records also explicitly recorded `git diff --check`. Desktop was not restarted in these reviews. Shared limitations in the archive introduction apply throughout.

The 3.1.2 and 3.1.3 installed-bundle checks used separate temporary harnesses with synthetic credentials and loopback upstreams. A test module delegated to the actual `createGatewayPlugin()` and request hooks, replacing only the outgoing URL and headers. Five non-streaming cases checked direct primary requests, the derived vision hook, and exact/prefix/suffix Fusion matches, including canonical context, hook selection, transformed messages, resolved model, and response conversion. Temporary files/processes were removed. These checks did not exercise the complete desktop wrapper routing/recovery stack or live streaming. Installed-bundle hashes identify inspected local artifacts, not reproducible builds or publisher signatures.
